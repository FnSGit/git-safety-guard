# git-safety-guard git破坏性命令守卫

## 的独特定位：备份后放行

npm 与 AI agent 生态，发现大量同类工具，但分属两种哲学：

### A. 阻断型（deny / fail-closed）—— 不让命令执行

┌─────────────────────────────────────────┬──────────────────┬──────────────────────────────────────────────┐
│ 工具 │ 形态 │ 做法 │
├─────────────────────────────────────────┼──────────────────┼──────────────────────────────────────────────┤
│ dcg │ 二进制 + │ 50+ 安全包、SIMD、覆盖 │
│ (Dicklesworthstone/destructive_command_ │ PreToolUse hook │ Claude/Codex/Gemini/Copilot/Oh My Pi 等 │
│ guard) │ │ │
├─────────────────────────────────────────┼──────────────────┼──────────────────────────────────────────────┤
│ codex-safeguard │ npm + Codex hook │ 拒绝 git reset --hard/checkout --/clean │
│ │ │ -fd/push --force │
├─────────────────────────────────────────┼──────────────────┼──────────────────────────────────────────────┤
│ vandith1/agent-guard │ ~60 行 shell │ 拒绝并 exit 2，要求人类介入 │
│ │ hook │ │
├─────────────────────────────────────────┼──────────────────┼──────────────────────────────────────────────┤
│ nuuxcode/codex-destructive-guard │ Python hook │ 拒绝 rm/git DROP/TRUNCATE 等 │
├─────────────────────────────────────────┼──────────────────┼──────────────────────────────────────────────┤
│ cjaston/airlock │ CLI + MCP + hook │ 拒绝危险命令 + 防幻觉包 + 防泄密 │
├─────────────────────────────────────────┼──────────────────┼──────────────────────────────────────────────┤
│ guard-git (bigpowers) │ shell hook │ 拒绝 destructive git + 主干保护 │
└─────────────────────────────────────────┴──────────────────┴──────────────────────────────────────────────┘

### B. 快照型（snapshot / 每回合全量备份）—— 事后整库回滚

┌────────────┬─────────────────────┬──────────────────────────────────────────────┐
│ 工具 │ 形态 │ 做法 │
├────────────┼─────────────────────┼──────────────────────────────────────────────┤
│ cowback │ npm CLI + fs.watch │ APFS CoW 克隆，cowback undo 整库回滚 │
├────────────┼─────────────────────┼──────────────────────────────────────────────┤
│ git-rewind │ bun CLI + Stop hook │ 每回合把 worktree 写进隐藏 ref，restore 回滚 │
├────────────┼─────────────────────┼──────────────────────────────────────────────┤
│ ckpt │ CLI + watch │ 隐藏分支每步 commit，ckpt restore N │
└────────────┴─────────────────────┴──────────────────────────────────────────────┘

### git-safety-guard 的独特定位：备份后放行

- A 类阻断命令；B 类全量快照。
- git-safety-guard 既不阻断、也不全量快照——它让命令照常执行（agent 有时确需 git checkout -- 排雷/清理并行
  worker 污染），但执行前把当前 diff 静默备份成 patch，并在输出里挂提示。哲学是"可能该丢、但绝不无声丢"。
